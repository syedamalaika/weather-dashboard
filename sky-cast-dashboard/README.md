# SkyCast - Premium Weather Experience

SkyCast is a state-of-the-art Weather Dashboard frontend built for clarity, precision, and visual impact. Featuring a stunning glassmorphism design, theme switching, and real-time tracking (simulated), it provides a comprehensive look at global weather conditions.

## ✨ Key Features

- **Glassmorphism UI**: High-end aesthetic using backdrop filters and linear gradients for a futuristic "HUD" feel.
- **Dual Theme Engine**: Seamlessly toggle between Light and Dark modes with persistent user preference using `localStorage`.
- **Intelligent Search History**: Tracks your last 5 searched cities for quick switching.
- **5-Day Visual Forecast**: Clear, card-based forecast with high-quality Font Awesome synchronization.
- **Dynamic Greetings**: Time-aware greeting messages (Good Morning/Afternoon/Evening).
- **Fully Responsive**: Adapts perfectly from large ultra-wide monitors to vertical mobile displays.

## 🛠️ Tech Stack

- **HTML5**: Semi-transparent semantic structure.
- **CSS3**: CSS Grid, Flexbox, and Custom Properties for the theme engine.
- **JavaScript (ES6)**: Modular architecture, dynamic rendering, and local state management.
- **Font Awesome**: Premium iconography for conditions and UI actions.

## 📂 Architecture

```text
sky-cast-dashboard/
├── assets/
│   ├── css/
│   │   └── style.css      # Design System & Theme Engine
│   └── js/
│       ├── data.js       # Global weather dataset
│       └── main.js       # App logic & DOM Orchestration
└── index.html            # Main Dashboard Entry
```

## 🚀 Installation & Launch

1. **Clone**: Download or clone the folder structure.
2. **Execute**: Open `index.html` in your choice of browser.
3. **Note**: For JS Module support, running through a local server (like **Live Server** on VS Code) is the recommended method.
